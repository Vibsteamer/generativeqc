# Psi4 restricted F12 component references

The CABS and restricted-pair fixtures contain input tensors and independent FP64 numerical answers for He, H₂, density-fitted H₂ and density-fitted H₂O. Each case has charge zero and multiplicity one. H₂ has bond length 1.4 bohr. Water uses O at (0,0,0) and H at (0,±1.430448,1.108157), in bohr. The source calculations used cc-pVDZ-F12, cc-pVDZ-F12-OptRI, β = 0.9 bohr⁻¹ and zero frozen occupied orbitals. Density-fitted intermediates use aug-cc-pVTZ-RI. This fixed β is part of the identity of these component tests.

The small JSON file separately records the output of Psi4 1.11 `MintsHelper.f12_cgtg(beta)` for β = 0.9, 1.4 and 2.2 bohr⁻¹. Each entry contains the Gaussian exponent in bohr⁻² followed by its signed coefficient. The geometry-dependent primitive tests integrate these recorded radial functions in real space, including mixed products.

`psi4_h2_robust_df.npz` and `psi4_water_robust_df.npz` preserve raw operator integrals, their own auxiliary metrics and Coulomb-fit coefficients for one occupied orbital per molecule (zero-based 0 and 4, respectively). Vᵢᵢᵢᵢ, Xᵢᵢᵢᵢ and Gᵢᵢₐᵦ come from Psi4's separate F12 routines on the same reference. Each fixture records the SHA-256 of the molecular tensor export supplying its data. The test rebuilds these values using rectangular three-center contractions and records individual errors. [Psi4 V/X construction](https://github.com/psi4/psi4/blob/v1.11/psi4/src/psi4/f12/f12_intermediates.cc)

The CABS fixture stores orthonormal-frame Fock matrices and the energy obtained from Psi4 1.11 `form_cabs_singles`. The pair fixture takes V, X, B, C, F, G and inverse denominators from the same archived molecular frames. Its totals, individual pair energies and displaced energies were regenerated by calling Psi4 1.11 `form_f12_energy` on these tensors. Per-pair printed energies carry twelve decimal places. The deterministic displacement uses a seed stored for each case, in V, X, B, C, G, D, symmetric F order. Each direction array is normalized by max(1, Frobenius norm). Perturb all seven arrays simultaneously in both directions with steps 3×10⁻⁴ and 10⁻⁴. The slopes are derivatives with respect to the intermediate tensors. [Psi4 1.11](https://github.com/psi4/psi4/blob/v1.11/psi4/src/psi4/f12/mp2.cc)

Run the reference algebra and the CUDA component qualification from the repository root. Build the native library with CUDA before running the CABS tests. The compiler benchmark uses the specified physical device target; use its matching compute capability.

```sh
PYTHONPATH=python:. python -m pytest -q tests/python/test_f12_pair_equations.py
GENERATIVEQC_TEST_CUDA=1 PYTHONPATH=python:. python -m pytest -q tests/python/test_f12_cabs_cuda.py
GENERATIVEQC_TEST_CUDA=1 PYTHONPATH=python:. python tests/python/test_f12_radial_integrals.py
PYTHONPATH=python:. python benchmarks/f12_cabs_component.py --output /tmp/f12-cabs.json
PYTHONPATH=python:. python benchmarks/f12_pair_component.py --arch sm_89 --cache /tmp/gqc-f12-cache --output /tmp/f12-pairs.json

```

The H₂ molecular-pair fixture contains all fitted density and operator factors for the occupied pair, including their CABS columns, the four operator metrics, extended Fock and exchange matrices. It also contains V, X, B, C and Coulomb values from the in-memory Psi4 contraction and its independent 3C(FIX) pair energy. Its embedded source digest identifies the same DF-H₂ archive used above. The extended Fock is reconstructed separately from one-electron and Coulomb-fit sources in the GPU qualification. The larger qualification additionally exercises all 15 H₂O pairs and checks their fitted-source adjoints.

`libint_df_primitives.json` records independent unnormalized Cartesian two- and three-center geminal integrals. Nine component signatures cover orbital g and auxiliary h, including ggh. The operators are f, f/r₁₂, f² and ∇₁f·∇₁f, using each of the three archived Slater ranges. Nuclear derivatives use the Gaussian raising/lowering identity with independently evaluated Libint2 values. The fixture preserves the reference adapter and parameter-file digests. The native benchmark additionally checks both nuclear finite-difference steps and translation invariance. This panel evaluates primitive source integrals.

`libint_contracted.json` adds 48 contracted source cases using normalized radial
coefficients from cc-pVDZ-F12 and aug-cc-pVTZ-RI. The independent Libint2 shell
engine performs contraction and pure d/g transformations itself; a separate
Cartesian projection checks their normalization and phase conventions. Derivatives
use independently evaluated raising/lowering contractions. The native test also
checks shared-atom motion: both orbital factors of one s–s product belong to the
same H nucleus. Four operators and β = 0.9, 1.4, 2.2 are retained. This is a scalar
source panel, not a complete molecular F12 force or whole-shell performance result.

`libint_contracted_full_shells.json` preserves those 48 rows and adds 24 signed,
externally weighted full Cartesian shell contractions: all 15 g–s metric
components and all 18 s–p–d three-center components. The independent Libint2
engine evaluates each shell value and raised/lowered derivative before the
external contraction. This panel qualifies radial reuse with the same physical
radial coefficients and four operators. `--timing-repeats 64` additionally measures
repeated rows with allocation, transfers and synchronization; these source timings
are not complete molecular F12 endpoint timings.

```sh
PYTHONPATH=python:. python -m pytest -q tests/python/test_f12_contracted_integrals.py
GENERATIVEQC_TEST_CUDA=1 PYTHONPATH=python:. python benchmarks/f12_contracted_integrals.py --fixture tests/reference_data/f12/libint_contracted.json --arch sm_89 --cache /tmp/gqc-f12-contracted --output /tmp/gqc-f12-contracted.json
```
