# Psi4 restricted F12 component references

The two compressed files contain input tensors and independent FP64 numerical answers for He, H₂, density-fitted H₂ and density-fitted H₂O. Each case has charge zero and multiplicity one. H₂ has bond length 1.4 bohr. Water uses O at (0,0,0) and H at (0,±1.430448,1.108157), in bohr. The source calculations used cc-pVDZ-F12, cc-pVDZ-F12-OptRI, β = 0.9 bohr⁻¹ and zero frozen occupied orbitals. Density-fitted intermediates use aug-cc-pVTZ-RI. This fixed β is part of the identity of these component tests.

The small JSON file separately records the output of Psi4 1.11 `MintsHelper.f12_cgtg(beta)` for β = 0.9, 1.4 and 2.2 bohr⁻¹. Each entry contains the Gaussian exponent in bohr⁻² followed by its signed coefficient. The geometry-dependent primitive tests integrate these recorded radial functions in real space, including mixed products.

The CABS fixture stores orthonormal-frame Fock matrices and the energy obtained from Psi4 1.11 `form_cabs_singles`. The pair fixture takes V, X, B, C, F, G and inverse denominators from the same archived molecular frames. Its totals, individual pair energies and displaced energies were regenerated by calling Psi4 1.11 `form_f12_energy` on these tensors. Per-pair printed energies carry twelve decimal places. The deterministic displacement uses a seed stored for each case, in V, X, B, C, G, D, symmetric F order. Each direction array is normalized by max(1, Frobenius norm). Perturb all seven arrays simultaneously in both directions with steps 3×10⁻⁴ and 10⁻⁴. The slopes are derivatives with respect to the intermediate tensors. [Psi4 1.11](https://github.com/psi4/psi4/blob/v1.11/psi4/src/psi4/f12/mp2.cc)

Run the reference algebra and the CUDA component qualification from the repository root. Build the native library with CUDA before running the CABS tests. The compiler benchmark uses the specified physical device target; use its matching compute capability.

```sh
PYTHONPATH=python:. python -m pytest -q tests/python/test_f12_pair_equations.py
GENERATIVEQC_TEST_CUDA=1 PYTHONPATH=python:. python -m pytest -q tests/python/test_f12_cabs_cuda.py
GENERATIVEQC_TEST_CUDA=1 PYTHONPATH=python:. python tests/python/test_f12_radial_integrals.py
PYTHONPATH=python:. python benchmarks/f12_cabs_component.py --output /tmp/f12-cabs.json
PYTHONPATH=python:. python benchmarks/f12_pair_component.py --arch sm_89 --cache /tmp/gqc-f12-cache --output /tmp/f12-pairs.json
```
