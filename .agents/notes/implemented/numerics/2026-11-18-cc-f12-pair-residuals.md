# Restricted explicitly correlated CC residual components

For an ordered fixed geminal pair, the standard approximation to the unweighted two-electron matrix element uses the occupied **and** virtual ordinary orbitals in the two-electron projector. The direct matrix element contains the product of the Coulomb and correlation operators. In general that element cannot be recovered by multiplying the separately projected Coulomb and geminal matrices in the orbital basis. The Coulomb subtraction uses a raw three-center density on one electron line and its Coulomb-metric fit on the other. Contract each line with the pair matrix before summing the auxiliary index to avoid materializing four free orbital indices. The input operator, fits, raw Coulomb and geminal integrals remain differentiable. The caller must propagate the fit through its metric solve.

The extra F12b geminal residual uses ordered, spin-free spatial CC singles and connected doubles. It contains the disconnected singles product and both distinct occupied–virtual matrix elements. The latter cannot be obtained by transposing the former for a fixed off-diagonal ordered geminal pair. The projection convention for these input blocks belongs to their integral provider. Fixed singlet/triplet coefficients and spatial pair multiplicities enter when assembling the energy. The ordinary singles and doubles residual corrections use a third compiler graph. It folds the fixed singlet and triplet cusp coefficients (1/2 and 1/4) over both orderings of each spatial pair. Its off-diagonal doubles block scatters to the transposed occupied pair, and each occupied index receives a distinct singles contribution. A diagonal pair contributes once. The Fock-coupling tensor is a separate input computed from the CABS–orbital Fock block and mixed geminal integrals at the same geometry. The small restricted water source reference uses a conventional RHF Fock, direct mixed-basis Psi4 integrals, an explicitly orthogonalized cc-pVDZ-F12-OptRI space, and independently converged conventional CCSD amplitudes. The three compiler graphs support source VJPs. A complete CCSD-F12b calculation additionally needs the F12a energy-functional terms, consistent integral and Hessian–vector actions, a self-consistent solve including these residual additions, and the associated relaxed nuclear response.

Adler, Knizia and Werner introduce the F12a approximation. Knizia, Adler and Werner distinguish the F12b variant. The explicit spatial-index equations for the common residuals, the additional F12b contribution and the projector appear in Knizia's dissertation, Eqs. (4.123)–(4.128), with the default simplification discussed after Eq. (4.134).
