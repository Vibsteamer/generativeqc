# Decision: Preserve distinct triples totals over one focal reference

Status: implemented
Date: 2026-11-22

The original focal role `triples` stays conventional so existing plan and
archive identities remain replayable. The two added roles represent Kállay
scaling and the explicitly correlated equation. A focal plan stores each
requested role once and selects a separate weighted recipe for each triples
method. Adding several triples increments to one total would count the same
physical correction multiple times.

The geometry owner groups requests by resolved basis and hands one matching
canonical reference and available lower-order results to a grouped triples
owner. That owner can reuse matched fitted integrals and CC state without
sharing across parent equations or orbital frames. Independent basis groups
retain their own ranks and reference identities. Energy-only displacements
replay the same variant weights and use the matching center reference.

An unpinned recipe can prefer Kállay scaling only when the provider certifies
both properties for all requested cardinals. The built-in provider has no
qualified owner for the new methods yet. The dispatch tests exercise exact
assembly, reference reuse, frozen replay and derivative scope with a mock
molecular owner.
